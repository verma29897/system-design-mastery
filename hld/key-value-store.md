# Distributed Key-Value Store

Specify `Get`, `Put`, conditional write, and delete plus value-size and durability
limits. Design partitioning, replication, membership, failure detection, hinted
handoff, read repair, compaction, and rebalancing. Compare leader-based and
leaderless quorums; define version/conflict handling and tunable consistency.

Drill: trace a write through a node failure, then explain how a returning replica
converges without serving permanently stale data.
