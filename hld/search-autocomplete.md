# Search Autocomplete

Define prefix suggestions, personalization, freshness, language, typo tolerance,
and latency. Compare trie/FST, search-index prefix queries, and precomputed top-k
prefix tables. Build an offline aggregation pipeline plus incremental updates;
rank by frequency, recency, quality, and user context. Filter unsafe suggestions.

Drill: support trending terms within one minute while retaining a stable,
low-latency serving index and safe rollback.
