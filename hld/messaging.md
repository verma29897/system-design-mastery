# Real-Time Messaging

Cover conversations, device sessions, message IDs, ordering scope, offline sync,
delivery/read receipts, attachments, presence, and push notifications. Route long-
lived connections through gateways to conversation-partitioned message services;
persist before acknowledgement and fan out per recipient/device.

Drill: reconnect after a network gap without message loss or duplicates. Explain
what ordering is guaranteed and how multi-device state converges.
