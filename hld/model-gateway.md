# Multi-Model Gateway

Normalize request/stream/error contracts across providers while retaining model
capabilities. Route using tenant policy, quality, latency, region, context length,
availability, and cost. Add quotas, admission control, deadlines, safe retries,
circuit breakers, fallback, token accounting, and policy-aware caching.

Drill: prevent retry/fallback amplification during a provider outage and preserve
an auditable record of which provider produced each response.
