# Document Q&A with RAG

Design ingestion, parsing/OCR, chunking, embeddings, hybrid retrieval, reranking,
context packing, generation, and citations. Carry tenant/document permissions into
every index entry and filter before exposing content. Version documents and make
updates/deletions propagate across derived stores.

Drill: define an evaluation set and metrics for retrieval relevance, groundedness,
citation correctness, latency, cost, and permission leakage.
