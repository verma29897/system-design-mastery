# Distributed Cache

Cover routing (client-side, proxy, consistent hash), replication, eviction,
admission, TTL, invalidation, serialization, and memory accounting. Address hot
keys, stampedes, node churn, cache penetration, and stale data. Decide whether
the cache is disposable or durable and make that contract visible to clients.

Drill: add nodes without creating a database traffic spike; quantify hit-rate
loss and describe warm-up, request coalescing, and overload protection.
